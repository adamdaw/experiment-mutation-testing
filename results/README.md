# Raw results

The reports in this directory were generated on 2026-10-07 with Node.js 24.21.0 and Stryker 10.0.0 in a container mounted at `/work`. Run the commands in the repository README to regenerate them.

- `full.json` and `reduced.json` are the raw Stryker JSON reports.
- `full-run-1.txt` and `full-run-2.txt` are independent full-run clear-text reproductions from clean checkouts.
- `reduced-run.txt` is the reduced-run clear-text output.
- `coverage.txt` is the output of `npm run coverage`.
